# کرمان تجربه — صفحه‌ی راه‌های ارتباطی

یک صفحه‌ی مستقل به سبک «زیلینک» برای کرمان تجربه که همه‌ی راه‌های ارتباطی را یک‌جا نشان می‌دهد:
اینستاگرام، تلگرام، واتساپ، تماس تلفنی، روبیکا و بله.

**پیش‌نمایش:** _(لینک دیپلوی)_

---

## تجربه‌ی کاربری

1. **اینترو:** پس‌زمینه‌ی نارنجی برند (`#F9711A`)، لوگوی «کرمان تجربه» تکه‌به‌تکه و از راست به چپ «نوشته» می‌شود.
2. **بالا بکشید:** سه فلش کوچک که پشت‌سرهم روشن و خاموش می‌شوند. ورود با کشیدن رو به بالا، تپ/کلیک، اسکرول یا کلید Enter.
3. **گذار:** صفحه‌ی سفید با یک دایره از پایین صفحه باز می‌شود.
4. **صفحه‌ی لینک‌ها:** تیتر با افکت pop، سپس کارت‌ها یکی‌یکی (stagger). موبایل: زیر هم — دسکتاپ: کنار هم.
5. **تعامل:** هاور/لمس ← سایه‌ی نارنجی ملایم و کج شدن آیکن. کلیک ← نوار نارنجی بالای صفحه و سپس رفتن به لینک.

## اجرا

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # خروجی استاتیک در پوشه‌ی out
```

پیش‌نیاز: Node.js 18.18 یا بالاتر.

## ✏️ تغییر لینک‌ها

فقط فایل [`src/config/links.ts`](src/config/links.ts) را ویرایش کنید:

```ts
{ platform: 'whatsapp', title: 'واتساپ', value: '09013702037' },
```

- فقط آیدی یا شماره نوشته می‌شود؛ URL نهایی (مثلاً `https://wa.me/989013702037` یا `tel:+98…`) خودکار ساخته می‌شود ([`src/lib/contact.ts`](src/lib/contact.ts)).
- حذف یک آیتم = حذف آن راه ارتباطی. جابه‌جایی آیتم‌ها = تغییر ترتیب نمایش.
- ارقام فارسی و `@` اول آیدی هم پذیرفته می‌شوند.
- متن‌های صفحه (تیتر، زیرتیتر، «بالا بکشید») هم در همین فایل (`SITE`) هستند.

## ساختار پروژه

```
src/
├─ config/links.ts            ← داده‌ی لینک‌ها و متن‌ها (تنها فایل قابل ویرایش برای محتوا)
├─ lib/contact.ts             ← ساخت URL درست برای هر پلتفرم
├─ font.ts + fonts/           ← فونت‌های محلی (هستی برای تیتر، ابر برای متن)
├─ app/
│  ├─ layout.tsx              ← lang="fa" dir="rtl"، فونت‌ها، متادیتا
│  ├─ page.tsx                ← Server Component: لینک‌ها را می‌سازد و به بخش کلاینت می‌دهد
│  └─ globals.css             ← توکن‌های رنگ و فونت (Tailwind v4 @theme)
└─ components/
   ├─ experience.tsx          ← state machine: intro → revealing → done
   ├─ intro/                  ← صفحه‌ی اینترو و لوگوی متحرک
   ├─ links/                  ← صفحه‌ی لینک‌ها، کارت، نوار بالای صفحه
   ├─ logo/                   ← داده‌ی وکتور لوگو + نسخه‌ی ثابت
   └─ icons/                  ← آیکن پلتفرم‌ها
```

## تصمیم‌های فنی

| تصمیم | دلیل |
|---|---|
| **Next.js (App Router) با `output: 'export'`** | صفحه کاملاً استاتیک است؛ خروجی روی هر هاستی (حتی بدون سرور Node) بالا می‌آید و سریع است. |
| **کانفیگ داده‌محور** (`links.ts` + `contact.ts`) | محتوا از منطق جداست؛ تغییر لینک بدون دانستن فرمت URL هر پلتفرم و بدون دست زدن به کامپوننت‌ها. |
| **لوگوی SVG + Motion به‌جای After Effects/Lottie** | حجم تقریباً صفر (بدون کتابخانه‌ی Lottie)، شارپ در هر اندازه، قابل کنترل و بازبینی در کد، هماهنگ با بقیه‌ی انیمیشن‌ها. لوگو از فایل رسمی وکتور شده و به ۹ تکه تقسیم شده است. |
| **انیمیشن «نوشتن» فارسی تکه‌به‌تکه** | حروف فارسی متصل‌اند؛ پس «حرف‌به‌حرف» یعنی رسم هر تکه‌ی متصل به ترتیب حرکت قلم (راست به چپ). هر تکه: کشیدن خط دور با `pathLength` ← پر شدن رنگ. |
| **دایره‌ی گذار با `clip-path` روی لایه‌ی `fixed`** | مرکز دایره همیشه پایین صفحه‌نمایش است (نه پایین محتوای اسکرول‌شده) و انیمیشن روی GPU نرم اجرا می‌شود. |
| **ناوبری با تأخیر در همان تب** | نوار نارنجی ~۰.۴۵ ثانیه پر می‌شود. `window.open` بعد از تأخیر توسط مرورگر بلاک می‌شود، پس از `location.href` استفاده شده. Ctrl/Cmd+کلیک و کلیک وسط رفتار پیش‌فرض را حفظ می‌کنند. |
| **رویداد `pageshow`** | برگشت با دکمه‌ی Back از bfcache، نوار نارنجی را ریست می‌کند. |
| **`<a>` واقعی برای هر لینک** | دسترس‌پذیری، کلیک‌راست/کپی لینک، SEO. |
| **فونت محلی با `next/font/local`** | بدون وابستگی به Google Fonts (مهم برای build در ایران)، preload خودکار و `font-display: swap`. |
| **آیکن‌های SVG درون‌خطی** | بدون کتابخانه‌ی آیکن و بدون درخواست شبکه‌ی اضافه؛ رنگ‌پذیر با `currentColor`. |
| **`prefers-reduced-motion`** | برای کاربرانی که انیمیشن را در سیستم‌عامل کم کرده‌اند، لوگو ثابت و گذارها کوتاه می‌شوند. |
